# NexAdmin Dashboard

Modern admin dashboard built with React, Vite, and Tailwind CSS.

## Features

- Responsive Design
- Modern UI
- Analytics Cards
- Activity Feed
- Clean Layout
- Fast Performance
- Mobile Friendly

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Icons

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
